# الكتاب الحي — الدراسات الإسلامية — الصف السادس — الفصل الثاني

كتاب عربي تفاعلي من اليمين إلى اليسار، على هيئة كتاب مفتوح فوق مكتب خشبي. يضم **٣٢ درسًا** حسب ترتيب فهرس طبعة ١٤٤٨هـ: **8 توحيد، 13 حديث وسيرة، 11 فقه وسلوك**.

**إعداد وتصميم: معلم برتبة (خبير) أ: محمد حسين جابر القحطاني — مدرسة معن بن عدي الابتدائية.**

## التشغيل

حمّل المستودع وافتح `index.html` مباشرة في متصفح حديث، أو شغّل خادمًا محليًا من جذر المشروع:

```sh
python3 -m http.server 8000 --directory .
```

ثم افتح `http://localhost:8000`. لا توجد حزم للتثبيت ولا مكتبات أو خطوط أو خدمات خارجية أثناء التشغيل. يعمل المحتوى دون اتصال بعد تنزيل ملفات المشروع.

## رحلة كل درس

1. **أقرأ وأفهم:** خلاصة، أهداف، شرح مفصل، مفردات تفاعلية، مستند الفكرة وتصحيح المفاهيم.
2. **أشاهد وأقرر:** موقفان، ملاحظة وقرار وتعليل وتغذية راجعة.
3. **أجرب وأكتشف وأختبر:** نموذج متحرك ومختبر مناسب للفكرة وسؤال تحقق وتأمل.
4. **أتحدى وأطبق:** ستة أسئلة اختيار، سؤالان كتابيان وإجابات مقترحة، ثم مهمة تطبيق ومعايير مراجعة.

الصوت اختياري باستخدام Web Audio، والحركة قابلة للإيقاف وتحترم تفضيل تقليل الحركة. الإجابات في ذاكرة الجلسة فقط؛ لا حسابات للطلاب ولا تتبع ولا إرسال للإجابات. الكتابة والتطبيق للمراجعة مع المعلم دون درجات آلية.

## تعديل المحتوى والتحقق

المصدر المعتمد هو `catalog.json`. بعد تعديله شغّل:

```sh
node build.cjs
node verify-expanded.cjs
```

يولد الأمر الأول `data.js` ونسخ الأقسام الثلاثة. يحتاج التطوير والتحقق إلى Node.js؛ لا يحتاج الطالب إليه. ملفات العرض `app.js` و`expanded.js` و`expanded.css`، والتنسيق الأساسي داخل `index.html`. النماذج مرسومة بـSVG وCanvas وCSS دون مكتبات.

## النسخة العامة ومصدر الكتاب

هذه نسخة مستقلة مفتوحة المصدر للشفرة والمواد التي أُعدت للمشروع. **لا تتضمن PDF الكتاب المدرسي أو صور صفحاته أو صوره الأصلية المستخرجة.** استُخدمت بدلًا منها الصور التعبيرية المولدة المتاحة للمشروع. جميع ملفات التشغيل موجودة مباشرة في جذر المستودع لتسهيل التنزيل والنقل. بقيت عناوين الدروس وترتيبها ومراجع صفحاتها؛ زر المصدر يعرض رقم الصفحة المطلوب مراجعتها في كتاب الطالب. انظر `SOURCES.md`.

للاستخدام المحلي، إذا كانت لديك نسخة يحق لك استخدامها، يمكنك إضافة صور الصفحات بصيغة `source/page-N.jpg` وتغيير `LOCAL_SOURCE_PAGES` إلى `true` في `public-source.js`. لا ترفعها إلى هذا المستودع؛ المسار مستبعد في `.gitignore`.
